**SweaxIris 1.1.1** — monitors carry Windows' own numbers.

- Monitors are numbered the way Windows numbers them in **Settings → Display**, not left to right. A screen standing on the left can be Display 2, and SweaxIris now says so.
- Every monitor tile, the record strip, the region tile and the monitor map show the number with the name: *Display 1 · LG ULTRAGEAR*, *Display 2 · A27 V2*. Two monitors of the same model can no longer be mixed up.
- Monitor tiles are listed in that order (1, 2, 3); the map below still shows where each one stands.
- Take thumbnails load by full path, so they also appear when the recordings folder was set as a relative path.

Everything else is as in [1.1.0](https://github.com/Sweax3169/sweaxiris/releases/tag/v1.1.0): the rebuilt studio and region picker, and the same recording engine.

Files: **SweaxIris-1.1.1-Setup.exe** (per-user install, no administrator) and **SweaxIris-1.1.1-win-x64.zip** (portable). Checksums in `SHA256SUMS.txt`.
Built with FFmpeg 7.1.1 (gyan.dev GPL v3 shared build, archive SHA-256 `9f28727e8b472a04c1d2e520aaa425dca82721b995139b35710091130ea6e699`). The program is not code-signed; SmartScreen may ask once (More info → Run anyway).
