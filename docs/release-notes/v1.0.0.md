**SweaxIris 1.0.0** — a screen recorder for Windows 10 and 11 that opens like a lens.

- Record a whole monitor, one window (even behind others) or a region you draw with a screenshot-style picker (Shift keeps 16:9, click a window to take its frame, arrows nudge, Enter records).
- Pause and resume into **the same file**: one clock for picture and sound, any number of pauses.
- Hardware encoding straight from video memory: NVIDIA NVENC and AMD AMF (H.264, HEVC, AV1 where available), Intel Quick Sync, and x264 as a fallback. Automatic picks the card that drives the monitor.
- 24 to 240 fps, output scaling on the GPU, constant quality or bitrate, encoder effort, keyframe interval, MP4 or MKV, mouse pointer on/off, 0/3/5/10 s countdown.
- System sound and microphone, each with switch, volume, device, live meter and sync offset; mute the mic on a key; separate tracks; one app's sound only when recording a window.
- Every shortcut is set by pressing it; macro keys (Pause, Scroll Lock, F13–F24 on their own) work, from inside games too.
- The studio window, the recording bar, the region frame and the countdown never appear in a recording.
- English and Turkish, light and dark, six coatings.

Files: **SweaxIris-1.0.0-Setup.exe** (per-user install, no administrator) and **SweaxIris-1.0.0-win-x64.zip** (portable). Checksums in `SHA256SUMS.txt`.
Built with FFmpeg 7.1.1 (gyan.dev GPL v3 shared build, archive SHA-256 `9f28727e8b472a04c1d2e520aaa425dca82721b995139b35710091130ea6e699`). The program is not code-signed; SmartScreen may ask once (More info → Run anyway).
